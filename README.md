# Г.Дөлгөөн — Хувийн портфолио

**SWE334 Интернэт програмчлал · Бие даалт 2**

🔗 Сайт: `https://[таны-сайт].vercel.app`
🔗 GitHub: `https://github.com/duk821/portfolio`

## Санаа

inacionakiti.com сайтын санаанаас сэдэвлэсэн: зочин эхлээд **"Намайг хэрхэн танихыг хүсэх вэ?"** гэсэн асуулттай тулгарч, хоёр замаас сонгоно.

- **01 Сайт** — өөрийн хурдаар, дуугүй. Дугаарласан хэсгүүдтэй минимал, редакцын загвар.
- **02 Түүх** — тоосонцроор өгүүлэх аялал. Гүйлгэх бүрт 2600 цэг шинэ дүрс рүү урсана: хөрөг → Улаан загалмай → гэр (СЭЗИС) → сүлжээ (Мексим) → сервер (М Банк) → `</>` → теннисний цохиур → "Дөлгөөн". Ард нь Web Audio-гоор үүсгэсэн "Салхи" дуу, бүлэг солигдох бүрт хонх дуугарна.

URL-аар шууд орж болно: `?v=site`, `?v=story`.

## Заавал байх 5 зүйл

1. **Танилцуулга** — "00" хэсэг: нэр, чиглэл, нэг өгүүлбэр, цэгээр зурсан хөрөг (`site/Site.jsx`)
2. **Миний тухай, ур чадвар** — "01 Тухай", "02 Туршлага", "04 Кодоос гадна"
3. **Бүтээлүүд** — "03 Бүтээлүүд": 6 бүтээл. Хулгана дээр нь очиход зураг нь хулганыг дагаж гарч, дарахад дэлгэрэнгүй цонх нээгдэнэ
4. **Холбоо барих** — "05 Холбоо": том имэйл холбоос, хуулах товч, GitHub, LinkedIn, Facebook
5. **Responsive, Vercel** — 760px media query; гар утсан дээр хөрөг дээр, текст доор байрлана, цэгийн тоо 1400 болж багасна

## Бүтээлч хэсгүүд (2 оноо)

| Онцлог | Тайлбар |
|---|---|
| ✨ Тоосонцрын хөдөлгүүр | `particles/` — canvas дээр мянга мянган цэг пүрш мэт зорилт руугаа татагдаж, хулганаас зугтана. Дүрсүүдийг нууц canvas дээр зураад пикселээс нь цэг болгон авдаг |
| 🧑 Цэгэн хөрөг | Өөрийн зургийн гэрэл/сүүдрээс тооцоолж цэгээр зурсан |
| 📖 Түүх горим | IntersectionObserver-ээр идэвхтэй бүлгийг тодорхойлж, дүрсийг солино |
| 🔊 "Салхи" дуу | 3 осциллятор + lowpass шүүлтүүр + LFO — гадны дууны файлгүй |
| 📅 Туршлагын скролл | Зүүн талд том он наалдаж үлдэн, гүйлгэхэд цифр бүр нь эргэлдэж солигдоно; баруун талын шугам явцаараа дүүрч, идэвхтэй ажил тодорно (`site/ExperienceScroll.jsx`) |
| 🚧 Одоо хийж буй | Accordion картууд: идэвхтэй карт өнгөтэй дэлгэгдэж, дотор нь хулганаар сэгсэрдэг цэгэн зураг (хурд хэмжигч, жааз, хөрөг); бусад нь босоо нэртэй нарийн карт (`site/NowBuilding.jsx`, `particles/DotCanvas.jsx`) |
| 🎛 Dock | Доод талын хөвөгч самбар: `</>` Лаб · Сайт/Түүх солих · дуу. Баруун захад хуудсыг гүйлгэх явцын хэмжүүр (`components/Dock.jsx`) |
| ⌨️ Лаб терминал | Dock-ийн `</>` товч → монгол командуудтай терминал |
| 🥚 Easter egg | Konami код (↑↑↓↓←→←→BA) → цас. Терминалд `морь`, `цас`, `теннис`, `бүжиг`, `sudo`, `rhel` |

## Технологи

React 19 · Vite · Canvas 2D · Web Audio API · цэвэр CSS · SVG · IntersectionObserver · Fontsource (Inter, Cormorant Garamond — монгол Ө, Ү үсэг дэмждэг, локалаар ачаалагдана) · Vercel

## Кодын бүтэц

```
src/
├── data.js                 ← Бүх агуулга + түүхийн бүлгүүд (story)
├── App.jsx                 ← Горим (gate / site / story), URL, дуу, Konami
├── audio.js                ← "Салхи" орчны дуу, хонх
├── particles/
│   ├── shapes.js           ← Дүрсүүдийг цэг болгох (хөрөг, гэр, сервер, текст ...)
│   └── ParticleField.jsx   ← Canvas, физик, хулганы харилцаа
├── components/
│   ├── Gate.jsx            ← "Намайг хэрхэн танихыг хүсэх вэ?" дэлгэц
│   ├── Story.jsx           ← Түүх горимын бүлгүүд
│   ├── Lab.jsx, Reveal.jsx, Thumb.jsx, Snow.jsx
├── components/Dock.jsx     ← Доод талын самбар, хэмжүүр
└── site/
    ├── Site.jsx            ← Сайт горим (00–05 хэсгүүд)
    ├── ExperienceScroll.jsx ← Том он + timeline скролл
    └── NowBuilding.jsx     ← Одоо хийж буй төсөл
public/me.jpg, me-dots.jpg  ← Зураг, цэгэн хөргийн эх
```
